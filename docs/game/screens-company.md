# Company Screens (FIN, CORP, HQ, LEAD)

## FIN — Financial Overview

**Key Figures** panel: Fixed Assets, Current Assets, Liquid Assets, Equity, Liabilities, Revenue (per currency). Below, recent cash bookings table: Description, Booked, Amount, with "Click to load more" pagination. Context bar: `FINBS` (Balance Statement), `FINIS` (Income Statement), `FINLA` (Liquid Assets).

## CORP — Your Corporation

Corporation overview with member/shareholder table: Company (link), Shares, Joined, Project, Location, Status, Cmd (`project` button). `Leave` button is a server action. Context bar: `COMG CORP-<id>` (corporation chat channel), `CORPFIN` (Finances), `CORPIVS` (Pending Invites), `CORPP` (Projects), `CORPNP` (New project).

## HQ — Headquarters

Reached from `BS` context bar or the HQ button on `BS <planet>`. Fields: Name, Address, Level ⓘ, Base permits ⓘ (used / max), Efficiency gains ⓘ. **Upgrade** section: Base permit increase ⓘ, Queue slot increase ⓘ, next-level efficiency gains, required materials table (Inventory, Assignment, Status) with `assign` buttons (server). **Relocation**: Site selector (`--`/Base + base list) and `Relocate` button (server). Context bar: `CO <own company code>`.

## LEAD — Leaderboards

Type select with ~20 leaderboards: APEX Representation Center level, Most bases, Highest company headquarters level, Most buildings, Most ships, Accumulated STL/FTL operating time, Total workforce (and per tier: pioneer/settler/technician/engineer/scientist), Accumulated faction reputation (and per faction), Most government terms served, Commodity production (with timeframe select: 7/30/90/180 days). `top ranks` / `own rank` buttons switch the view. Columns: Rank, Score, Company, User, Corporation (all links).
